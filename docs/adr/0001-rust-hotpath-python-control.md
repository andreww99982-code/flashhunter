# ADR 0001: Rust в горячем пути, Python в контуре управления

**Дата:** 2026-09-14 · **Статус:** принято

## Контекст

Бюджет обработки блока — 5 мс от наблюдения блока до отправки bundle (ТЗ §1.2).
В этот бюджет входит: разбор блока, обновление индекса пулов, поиск циклов,
оценка размера, локальная симуляция (revm), сборка и подпись транзакции,
отправка во все релеи. Конкуренты — другие боты с теми же лимитами; проигрыш
в 1 мс означает проигранный блок и потраченный газ.

При этом 90% кода — операционная логика: дашборд, лимиты риска, аудит, история,
бэктесты, интеграции уведомлений. Её важнее быстро менять, чем быстро исполнять.

## Варианты

1. **Всё на Python.** Быстрая разработка, но интерпретатор + GIL дают десятки
   миллисекунд на горячем пути даже с `asyncio` и `orjson`.
2. **Всё на Rust.** Максимальная скорость, но панель управления и бэктесты
   писались бы в разы дольше; найм и поддержка дороже.
3. **Гибрид: Rust — горячий путь, Python — управление.** (выбрано)

## Решение

| Слой | Язык | Ответственность |
|------|------|-----------------|
| Горячий путь | Rust (edition 2021) | Ингестор блоков, индекс пулов, граф-поиск циклов, симулятор (revm), сборка bundle, клиент релеев |
| Контур управления | Python 3.12 | Риск-движок, API, панель, БД, аудит, бэктест, алертинг, деплой-скрипты |
| Контракты | Solidity 0.8.24 | Атомарное исполнение сделки и защита средств |

Связь слоёв: Redis Streams/NATS для событий, gRPC (`proto/flashhunter.proto`)
для синхронных вызовов; в локальном режиме всё живёт в одном процессе Python.

## Последствия

**Плюсы:** горячий путь укладывается в бюджет; управляющая логика меняется
за минуты; риск-движок на Python читается и аудируется аналитиком.

**Минусы (принимаем осознанно):**
* два тулчейна в CI (cargo + pytest), дольше сборка;
* граница между слоями требует дисциплины: изменение структуры данных правится
  в proto и генерируется в оба рантайма;
* в локальном docker compose Rust не собирается (тяжёлая сборка) — сервисы
  заменяются моками внутри Python-процесса; для прод-сборки есть `Dockerfile.rust`.
