# Echidna: инварианты FlashHunter

Каталог содержит property-based фаззинг (Echidna) для контрактов арбитража.
Echidna вызывает внешние функции в произвольном порядке и проверяет, что
инварианты безопасности никогда не нарушаются.

## Запуск

```bash
# локально (нужен echidna >= 2.2)
make echidna

# или напрямую
echidna echidna/EchidnaFlashHunter.sol --contract EchidnaFlashHunter --config echidna/EchidnaConfig.yaml
```

## Инварианты

| # | Инвариант | Почему важно |
|---|-----------|--------------|
| 1 | Баланс Aave не уменьшается | Флеш-кредит всегда возвращается: иначе транзакция ревертится, но мы проверяем и «долгую» стабильность |
| 2 | Роли (owner/keeper) недоступны посторонним | Keeper-ключ — единственный, кто двигает деньги |
| 3 | Нет «зависшего» нативного баланса | Нативный токен не должен застревать в контракте |
| 4 | Учёт прибыли не превышает баланс | Защита от ошибок учёта, из-за которых sweep может провалиться |
| 5 | Нет нулевых адресов в ролях | Защита от блокировки управления контрактом |

Песочница проекта Echidna может не содержать — тогда прогон выполняется в CI
(см. `.github/workflows/ci.yml`, job `contracts`).
