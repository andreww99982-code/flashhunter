# FlashHunter Contracts

Смарт-контракты FlashHunter: флеш-кредитный арбитраж, ликвидация, JIT-ликвидность
и адаптер кросс-чейн интентов. Solidity **0.8.24**, сборка и тесты — **Foundry**,
инварианты — **Echidna**.

## Состав

| Файл | Назначение |
|------|-----------|
| `src/FlashLoanArbitrage.sol` | Ядро арбитража: флеш-кредит Aave V3, цепочка свопов, проверка прибыли |
| `src/Liquidator.sol` | Ликвидация позиций Aave V3 с флеш-кредитом на погашение долга |
| `src/JITVault.sol` | JIT-ликвидность в Uniswap V3 (mint → swap → burn → collect) |
| `src/BridgeAdapter.sol` | Кросс-чейн интенты: блокировка средств, исполнение солвером, комиссия ≤ 25 bps |
| `src/interfaces/*` | Минимальные интерфейсы ERC-20, Uniswap V2/V3, Aave V3, WETH |
| `src/libraries/SafeERC20Lite.sol` | ERC-20 без «пустых» ревертов (USDT-совместимость) |
| `src/mocks/*` | Моки токенов, пар, роутеров и пула Aave для тестов |

## Быстрый старт

```bash
# зависимости
forge install foundry-rs/forge-std

# сборка и тесты
forge build
forge test -vv

# фаззинг + инварианты (в CI: 512 ранов)
FOUNDRY_PROFILE=ci forge test

# покрытие
forge coverage

# инварианты Echidna
make echidna

# деплой в сеть (адреса Aave берутся из .env)
forge script script/Deploy.s.sol:Deploy --rpc-url $ETH_RPC_URL --broadcast --verify
```

## Переменные окружения для деплоя

| Переменная | Описание |
|-----------|----------|
| `DEPLOYER_PRIVATE_KEY` | Ключ деплоера (никогда не коммитится) |
| `KEEPER_ADDRESS` | Горячий кошелёк бота (единственный, кто запускает сделки) |
| `AAVE_POOL_ADDRESSES_PROVIDER` | Провайдер адресов Aave V3 в целевой сети |
| `WETH_ADDRESS` | WETH/WMATIC/WAVAX в целевой сети |
| `ETH_RPC_URL` / `BASE_RPC_URL` / `ARBITRUM_RPC_URL` | RPC для деплоя |
| `ETHERSCAN_API_KEY` / `BASESCAN_API_KEY` | Ключи верификации |

## Политика безопасности

Проект сознательно **не** реализует и не будет реализовывать:

* сэндвич-атаки на пользовательские свопы (исключено этической политикой ТЗ §0);
* эксплойты, взломы, атаки на другие боты;
* обфускацию кода и скрытие потока средств.

Все операции — только «честный MEV»: арбитраж, ликвидации, JIT-ликвидность,
бэкран, исполнение интентов по цене, ограниченной сверху.

### Ключевые гарантии контрактов

1. **Атомарность**: любая сделка либо приносит прибыль ≥ `minProfit`, либо ревертится целиком — потерять средства на газе/флеш-комиссии невозможно.
2. **Роли**: двигать деньги может только `keeper`; менять роли и снимать прибыль — только `owner` (мультисиг).
3. **Пауза**: `setPaused(true)` мгновенно останавливает все операции (используется kill-switch риск-движка).
4. **Ограничение комиссии интентов**: `MAX_FEE_BPS = 25` (0.25%) — зашито в контракт, пользователь не может быть обманут.

## Локальные адреса (после `make deploy-local`)

Anvil поднимается на `http://127.0.0.1:8545`, адреса контрактов сохраняются
в `deployments/local.json` и подхватываются ботом при `CHAIN_MODE=local`.
