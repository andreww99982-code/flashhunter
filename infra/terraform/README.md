# Terraform: инфраструктура FlashHunter в AWS

## Состав

| Ресурс | Назначение |
|--------|-----------|
| VPC + приватные/публичные подсети | Бот без публичного IP, но с исходящим доступом к RPC/релеям через NAT |
| EC2 `c7i.large` | Горячий путь: высокая single-thread производительность важнее числа ядер |
| RDS Postgres (Multi-AZ) | Транзакционные данные: сделки, лимиты, аудит |
| S3 + lifecycle | Бэкапы: дампы Postgres, отчёты бэктестов; версионирование + переход в IA |
| Secrets Manager | JWT, RPC-ключи, авторизация релеев (приватные ключи кошельков — только KMS, см. ADR 0006) |
| KMS | Шифрование диска, секретов, бакетов; ротация ключей включена |
| Cloudflare | DNS панели + прокси (origin скрыт, WAF перед панелью) |

## Использование

```bash
cd infra/terraform
terraform init

# Планирование с проверкой изменений (никогда не apply без review плана)
terraform plan -var "owner_email=ops@example.com"

# Применение
terraform apply -var "owner_email=ops@example.com" \
  -var "allowed_admin_cidrs=[\"203.0.113.10/32\"]"

# Забрать инвентори для Ansible
terraform output -json > /tmp/fh-outputs.json
```

## Важные замечания

1. **Состояние в S3 + DynamoDB**: без блокировки два параллельных `apply` могут
   уничтожить NAT-шлюз или подсеть, а это простой торговли.
2. **Приватные ключи кошельков не хранятся в Terraform.** В состоянии только ссылки
   на KMS-ключ; ключи инжектируются на ноду при деплое и живут в памяти/шифрованном файле.
3. **`disable_api_termination = true`**: инстанс нельзя снести одним кликом из консоли.
4. **IMDSv2 обязателен**: защита от SSRF-кражи роли инстанса (RPC-прокси — типичный вектор).
5. **`allowed_admin_cidrs` по умолчанию `10.0.0.0/8`**: панель не должна светиться в интернет.
   Доступ — только через VPN/bastion.
